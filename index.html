About This Project

This project utilizes a machine-learning backend built with Python, FastAPI, and scikit-learn. It processes various inputs—ranging from daily screen time to academic status—to generate a predictive score.

Disclaimer: This tool is strictly for educational and project demonstration purposes. The predictions generated by the algorithm do not constitute, and should not be interpreted as, professional medical advice or clinical diagnosis.
